# FGet Private Video (Web)

เว็บแอปสำหรับหา URL วิดีโอ Facebook จากซอร์สของหน้า แล้วเปิด URL วิดีโอโดยตรงในเบราว์เซอร์

## ใช้งาน

1. เปิดเว็บแอปและ Facebook ในโปรไฟล์เบราว์เซอร์เดียวกัน จากนั้นเข้าสู่ระบบ Facebook ตามปกติ
2. วาง URL วิดีโอ Facebook แล้วคัดลอกลิงก์ดูซอร์ส
3. เปิดลิงก์ซอร์สในเบราว์เซอร์ คัดลอกซอร์สทั้งหมด แล้วนำมาวางในเว็บแอป
4. กดค้นหาวิดีโอ แล้วเลือกเปิด/ดาวน์โหลด เว็บแอปจะเปิด CDN ในแท็บใหม่
5. หากแท็บใหม่เล่นวิดีโอแทนการบันทึก ให้คลิกขวาที่วิดีโอแล้วเลือกบันทึกวิดีโอเป็น

เว็บแอปแยกข้อมูลในเบราว์เซอร์ของผู้ใช้ ไม่ขอหรือเก็บรหัสผ่าน Facebook และไม่ส่งซอร์สไปยังเซิร์ฟเวอร์ของแอป การเปิดลิงก์จากแท็บใหม่ให้เบราว์เซอร์เป็นผู้ขอวิดีโอ จึงใช้การเข้าสู่ระบบและนโยบายคุกกี้ของเบราว์เซอร์นั้นได้

## คิวหลายลิงก์

ส่วน “คิวค้นหาและดาวน์โหลดอัตโนมัติ” ต้องใช้ส่วนขยายใน `browser-extension/` เพื่อเปิดแต่ละโพสต์ในโปรไฟล์ Facebook เดียวกัน อ่านข้อมูลจากหน้า และส่งไฟล์เข้าตัวจัดการดาวน์โหลดของเบราว์เซอร์ **ส่วนขยายทำงานทีละรายการตามลำดับ** และรอให้ไฟล์ปัจจุบันเสร็จก่อนเริ่มรายการถัดไป คุณวางลิงก์เพิ่มได้ขณะคิวกำลังทำงาน

ใน Edge เปิด `edge://extensions`, เปิด Developer mode, เลือก **Load unpacked** แล้วเลือกโฟลเดอร์ `browser-extension` จากนั้นรีเฟรชเว็บแอป ส่วนขยายขอสิทธิ์จัดการแท็บ/ดาวน์โหลดและอ่านหน้า Facebook เพื่อค้นหาลิงก์วิดีโอ โดยไม่ขอสิทธิ์อ่านหรือเก็บคุกกี้และรหัสผ่าน

ลิงก์ CDN ของ Facebook อาจหมดอายุหรือถูกปฏิเสธด้วย 403 หากเกิดขึ้น ให้คัดลอกซอร์สใหม่หรือเพิ่มลิงก์อีกครั้งขณะล็อกอิน เว็บแอปไม่สามารถเปลี่ยนสิทธิ์เข้าถึงวิดีโอได้ วิดีโอที่แยกเสียงกับภาพยังไม่สามารถรวมสตรีมในเบราว์เซอร์ได้

## พัฒนา

- `npm run dev -- --host 127.0.0.1 --port 4173` เปิดเว็บแอปในเบราว์เซอร์
- `npm run build` สร้างไฟล์เว็บใน `dist/client` พร้อมไฟล์สำหรับ handoff ไปยัง Sites
- `npm run preview` ดูไฟล์ที่ build แล้ว
